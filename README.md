## 🍽️ Installation
#### iOS
##### Setting up
```
npm install
cd ios
pod install
```
##### Running on Simulator
```
npm run ios -- --simulator="{sumulator name}" 
```
##### Running on Device
```
npm run-ios --device "{device name}"
```
